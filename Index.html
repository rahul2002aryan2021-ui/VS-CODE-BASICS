VS Code Basics Guide

Welcome to the complete beginner guide of Visual Studio Code. Learn VS Code step-by-step with practical examples.

💻 VS Code Kya Hai?

Visual Studio Code (VS Code) Microsoft ka ek free aur lightweight Code Editor hai. Iska use HTML, CSS, JavaScript, Python, PHP aur bahut si programming languages ka code likhne ke liye kiya jata hai.

✨ VS Code Ki Features

  • ✔ Free aur Fast
  • ✔ Windows, macOS aur Linux Support
  • ✔ Built-in Terminal
  • ✔ Thousands of Extensions
  • ✔ Auto Complete (IntelliSense)
  • ✔ Live Preview Extension Support
💡 Tip: Agar aap HTML, CSS aur JavaScript seekh rahe hain to VS Code sabse best editor hai.

📥 Download & Install VS Code

VS Code ko download aur install karna bahut hi easy hai. Bas neeche diye gaye steps follow karein.

Step 1

Official VS Code website open karein.

Step 2

Apne Operating System (Windows, macOS ya Linux) ke hisaab se Download button par click karein.

Step 3

Download hone ke baad setup file open karein aur Next → Next → Install par click karein.

Step 4

Installation complete hone ke baad Finish par click karein aur VS Code open karein.

⚠ Important: Installation ke time "Add to PATH" aur "Open with Code" wale options ko tick karna na bhoolen.

🖥️ VS Code Interface

Jab aap pehli baar VS Code open karte hain, to screen par alag-alag sections dikhai dete hain. Har section ka apna alag kaam hota hai.

📁 Explorer

Project ki files aur folders dekhne ke liye.

📄 Editor

Yahin par aap HTML, CSS, JavaScript ya kisi bhi language ka code likhte hain.

💻 Terminal

Commands run karne aur projects execute karne ke liye.

🧩 Extensions

Naye features add karne ke liye, jaise Live Server aur Prettier.

⚙️ Settings

Theme, Font Size aur baaki preferences change karne ke liye.

📊 Status Bar

Neeche wali bar jahan language, errors aur project information dikhti hai.

📂 Explorer (Files & Folders)

Explorer VS Code ka woh section hai jahan aap apne project ki sabhi files aur folders ko manage karte hain.

Step 1 - Folder Open Karein

File → Open Folder par click karein aur apna project folder select karein.

Step 2 - New File Banayein

Explorer me New File (+) icon par click karein aur file ka naam index.html likhein.

Step 3 - New Folder Banayein

New Folder icon par click karke folder banayein, jaise css, js aur images.

Step 4 - Project Structure

My Project/
│── index.html
│── css/
│     └── style.css
│── js/
│     └── script.js
│── images/
💡 Tip: Hamesha project ko ek folder ke andar hi banayein. Isse files manage karna aur project ko future me update karna bahut aasaan hota hai.

💾 Save & Auto Save

Code likhne ke baad file ko save karna bahut zaroori hota hai. Agar file save nahi hogi to changes browser me dikhai nahi denge.

💾 File Save Kaise Kare?

  • ✔ Windows: Ctrl + S
  • ✔ Mac: Cmd + S
  • ✔ Ya File → Save par click karein.

⚡ Auto Save Enable Karein

File → Auto Save par click karein. Iske baad file har change ke saath automatically save hoti rahegi.

💡 Tip: Beginners ke liye Auto Save ON rakhna best hai, taaki save karna bhoolne par bhi changes lose na hon.

🖥️ Integrated Terminal

VS Code me built-in Terminal hota hai jisse aap commands run kar sakte hain bina alag Command Prompt ya PowerShell khole.

📂 Terminal Open Karne Ke Tarike

  • ✔ Menu → Terminal → New Terminal
  • ✔ Shortcut: Ctrl + `

📌 Terminal Ka Use

  • ✔ Project run karna
  • ✔ Git commands chalana
  • ✔ npm install karna
  • ✔ Python ya Node.js commands run karna
💡 Tip: Agar aap HTML/CSS/JavaScript hi seekh rahe hain, to shuruaat me Terminal ka basic use samajhna hi kaafi hai.

🔌 Essential Extensions

VS Code ki sabse badi khasiyat uski Extensions hain. Agar aap Web Development shuru kar rahe hain, to ye 3 Extensions zarur install karein.

🌐 Live Server

HTML website ko browser me Live Preview ke saath run karne ke liye.

🎨 Prettier

Code ko automatically clean aur properly format karta hai.

🏷️ Auto Rename Tag

Opening HTML tag change karne par closing tag bhi automatically update ho jata hai.

💡 Tip: Beginners ke liye sabse pehle Live Server install karna chahiye.
